# 关于我穿越修仙世界搞军工这件事

SillyTavern / 酒馆助手 MVU 开放修仙世界角色卡项目。

当前阶段：Phase 0 总设计头脑风暴。尚未开始 schema、InitVar、世界书成品、状态栏、组件或完整角色卡构建。

## 权威入口

- `plan.md`：当前总计划案与已冻结裁定。  
- `脑暴协作风格.md`：本地与云端共同遵守的头脑风暴方式。  
- `CHATGPT云端续接.md`：可直接交给 ChatGPT 云端任务的完整续接包。  
- `头脑风暴/`：按日期保存的裁定纪要。

## 当前停点

核心玩法、构筑工坊、天罡尸魁术、灵械通鉴、以沫、龙曦、可叠加世界基调、基调改革，以及九域、情报五层、16 势力骨架已经冻结。真龙混战与威压、尸修伪装、僵尸娘怪人误判、灵械炼器新分支、十六席态度表、神人可穿越与官方魔法少女神人样本也已冻结。

当前地图 Pages 预览只算可推翻的视觉原型，不属于设定正典。恢复脑暴时，从该神人的姓名用字，或十六席现任人物继续。

## 脑暴回落

用户明确确认的新增内容，默认在同一轮更新 `plan.md` 与当日脑暴纪要并提交到 Git。若后续内容修改或冲突于既有冻结裁定，先说明旧基线与影响，经确认后再改并保留变更记录。

## 工程边界

- 开放世界，不设置强制通关主线。  
- 远程工坊内容不能直接写正式 MVU 状态。  
- 在变量树经过复述确认前，不进入 schema 和组件实现。  
- 后续正式构建、验证、打包与 SillyTavern 真机验收遵守角色卡工作区工程规约。
