## 脑暴回落

用户逐项确认的新增内容先进入本地审批草稿；一个角色或相邻主题补齐后统一提供审批摘要。只有用户明确审批通过，才更新 `plan.md`、当日脑暴纪要与必要续接文件，并一次性 commit / push。若内容修改或冲突于既有冻结裁定，先说明旧基线与影响，经审批后再改并保留迁移记录。

## 工程边界

- 开放世界，不设置强制通关主线。  
- 远程工坊内容不能直接写正式 MVU 状态。  
- MVU / Zod 变量树、事实变量与派生计算分工、境界和灵械数值包络均已后置；在另行复述确认前，不进入 schema 和组件实现。
- 后续正式构建、验证、打包与 SillyTavern 真机验收遵守角色卡工作区工程规约。
