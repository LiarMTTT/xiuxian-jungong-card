# 2026-08-12 构筑工坊、世界基调与固定地图回落纪要

## 核心玩法与传承

- 核心玩法四选一：什么都不要、天罡尸魁术、灵械通鉴、我全都要。  
- 核心玩法不计构筑点数，也可以什么都不要，完整体验普通修仙世界。  
- 两套传承以自然记忆和可主动检索的识海典籍存在，知识完整但实施受现实条件限制。  
- 降临后不能在菜单中随时切换，只能重开、管理员测试或在剧情中真实获得新传承。  
- 第一件灵械必须由 {{user}} / 玩家自行构思、取材和制造，传承不自动发放成品。  
- 天罡尸魁术自带可成长的尸宫。僵尸娘数量不设硬上限，不为 AI 扮演便利编造槽位。

## 境界与点数构筑

- 境界阶梯：凡人、炼气、筑基、金丹、元婴、化神、炼虚、合体、大乘、渡劫、飞升。  
- 首版开局可自定义当前境界至渡劫；飞升后境界暂不加入官方池。  
- 预算支持 50 / 100 / 200 / 自定义 / 无限点数。  
- 负面词条可用负成本返还点数，不设强制返还上限。  
- 点数只衡量降临时的初始条件；负面后续治愈不追缴，正面后续失去不退款。  
- 高境界玩家进入黄金古墓时，以沫不再被强制动态强化为致命小 BOSS。

## 构筑工坊与二创

- 支持从一个自定义天赋到整套构筑包的任意发布粒度。  
- 发布内容必须自带成本标注；下载后可以拆解、组合、编辑本地成本并二创。  
- 二创生成新的内容 ID，记录来源包与版本，不覆盖原作。  
- 构筑器只做结构、必填字段、数值类型和包损坏检查，不接 API 检查是否超模、矛盾或“有 Bug”。  
- 只有确认降临后，卡内可信逻辑才能把最终构筑写成正式状态；远程包不能直接写 MVU。  
- 与星月共享创意工坊服务器；角色与明确兼容内容可以互通，明显不符合世界观的内容不自动互通。

## 世界基调

- 世界基调是固定世界书条目，可多选、可不选、可自创、不计点数。  
- 自定义基调可描述服装、审美、礼法、行事风格、社会伦理、修行倾向等。  
- 适用范围可以是全世界、地域、皇朝、城市、宗门、组织、种族、群体或地点。  
- 确认降临后基调冻结，不能在控制中心反复启停；只能通过世界内真实改革或历史变化发生偏转。  
- 神人数量与活跃程度由条目正文决定，不做百分比滑块。

### 天道遮眼

- 困难基调，修仙生态极尽残酷无道，众生为飞升、成仙或成神不择手段。  
- 玩家与 NPC 都不能口胡作弊；能力、资源、情报、时间和因果对称结算。  
- 系统不主动生成从起点就完全无解的必死局，但玩家可以自行关闭所有生路。  
- 飞升可能涉及升仙路断绝、献祭修仙界、外域入侵、虚假上界、天道残缺或一人扛起世界。  
- 最终真相不固定，直到飞升终局才依据整局事实与玩家行动收束。

### 沃土世界

- 简单基调，修仙界相对和平、自由、开放，资源与正常上升空间较充足。  
- 飞升道路可以正常开放，不默认隐藏献祭骗局。  
- 适合生活、经营、建设、恋爱、长期养成与自由探索。

### 神人世界

- 混沌基调，修行者和普通人中存在相当数量现代互联网语义的“神人”。  
- 行为跳脱、动机清奇、经常让人眼前一黑，但仍须遵守实力和因果。  
- 普通人仍是维持社会日常的主体，并形成了大量识别和躲避神人的民间经验。

## 基调偏转与改革

- {{user}}、NPC、宗门、皇朝、商会和其他势力都能推动改革。  
- 改革采用萌芽、扩散、制度化、固化四阶段，不设置百分比。  
- 改革必须具有推动者、动机、阻力、现实过程和影响范围。  
- 改革可以失败、倒退、异化或只在局部成功。  
- 偏转结果作为新条目叠加，旧基调保留为历史原因，不通过菜单删除过去。

## 固定地图与势力

- 主要宗门和势力固定，未来与正式地图一起确定驻地、资源、关系和初始格局。  
- 地图固定初始地理与势力骨架，但允许领地易主、宗门兴衰、迁徙、分裂、合并、改革和灭亡。  
- AI不得临时生成凌驾所有官方势力、却声称自古存在的超级宗门。  
- 新组织可以在剧情中成立，并通过人员、资源、技术、战争和政治积累逐渐成长。  
- 地图必须同时支撑政治地缘、交通时间、灵材与军工资源、古墓阴脉、上古遗迹和龙族遗产。

## 合欢宗

- 合欢宗是基础世界中的官方常驻大宗门。  
- 固定总纲包括情欲、阴阳、双修、魅术、神魂、婚契、关系因果、血脉、艺术、礼仪与情报网络。  
- 不简化成单一色情宗门，允许多个理念不同的内部派系。  
- 总坛位置、正魔 / 中立定位、宗主、战力、主导派系与外交关系留待地图阶段拍板。  
- 合欢宗可拥有独立服装、伦理和行事基调，作为局部势力世界书条目触发。
