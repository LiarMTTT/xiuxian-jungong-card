# 2026-08-13 以沫阶段性冻结与角色线转向

> 状态：已确认并回落  
> 权威摘要：`plan.md` plan-v1.4  
> 适用范围：当前角色脑暴队列与以沫人物线的恢复边界  
> 不改变：任何已经归档的以沫设定

## 1. 本轮确认

1. **以沫的设定暂时冻结。**  
2. 既有的身份、外貌、体术、辨识、性耐力曲线、尸魁状态与黄金棺 / 尸宫门关系全部原样保留。  
3. 尚未确定的陨落原因、封棺者、黄金棺原属与古墓形成、原身性格、重要关系、代表性成名战、具体神通和完整法宝规则也暂不继续补写。  
4. 本阶段可以设计其他角色；角色脑暴从龙曦、顾小满或十六席现任人物继续。  

## 2. “暂时冻结”的含义

- 这是角色脑暴队列的阶段性停点，不是删除未定项，也不是把空白擅自补成正典。  
- 后续只有总监明确要求“恢复以沫”或明确提出修改时，才重新打开她的人物线。  
- 若未来修改已冻结内容，仍须先列出旧基线、冲突点与影响范围，经确认后保留迁移记录再回写。  
- 其他角色可以与既存的以沫设定发生兼容关系，但不得借此绕过冻结、反向替她补写死因、关系或性格。

## 3. 当前角色队列

1. 龙曦：上古身份、外貌人格、封印地点、父亲与婚约正文、非真龙血脉路线；  
2. 顾小满：外貌、功法与战斗定位、好运边界、开放世界相遇材质；  
3. 十六席现任人物：从单个关键人物逐步建立，不一次性铺满十六人。

变量树、schema、世界书成品、状态栏与完整角色卡仍未开工。
