# 2026-08-13 上古混战、真龙威压与镇魂地脱钩

> 状态：已确认并回落  
> 权威摘要：`plan.md` plan-v0.9  
> 适用范围：上古大战参战方类别、真龙威压技能、须弥梵院镇魂地与大战脱钩  
> 不包含：真仙 / 真神 / 魔神的当世生态、与飞升真相的关系、完整下级龙种名录、十六势力态度正文

## 1. 本轮确认

1. 上古大战是 **龙族与真仙、真神、魔神之间的混战**，不是单线内战，也不是当前十六席发动的灭龙战争。  
2. 真龙威压 **可自行收放**；真龙血脉自带 **真龙威压** 技能。跨阶也有明显效果，但无法完全弥补真正的境界差距。  
3. 须弥梵院的古战场 / 镇魂地 **本轮不挂钩** 这场大战，另有来历。  
4. 遗迹清单不再继续展开；下一主题转入十六势力对普通尸修、天罡尸魁术与灵械工业的态度。

## 2. 混战，不是清剿

- 参战方是龙族、真仙、真神、魔神。混战意味着多方互砍，不是「全体神仙联合屠龙」。  
- 真仙、真神、魔神不是当前十六席的公开后台，也不写成开局就凌驾九域的第十七势力。  
- 不把「飞升 = 变成真仙 / 真神」写进正典；飞升真相仍按天道遮眼规则，到终局才收束。  
- 现有势力仍只继承废墟、材料、解释权；须弥梵院的镇魂地不在本轮算作这场混战的战场。

## 3. 真龙威压：可收放的技能

- 威压是可自行收放的能力，不是被动常开光环。  
- 「真龙血脉后裔」自带真龙威压技能。  
- 对下级龙种仍是巨大精神压制；对其他存在是可感知的威压。  
- 跨阶也有明显效果，但不能拿来完全抹平真正的境界差距：低阶血脉持有者能让更高阶的蛟明显不适、滞涩、心神受压，却不能因此把合体蛟祖盯死。  
- 与旧裁定兼容：龙曦是完整真龙，强度过高，平时必须长期主动收着；「可收放」是控制方式，不是她可以随便把完整真龙威压当社交礼仪。

## 4. 须弥梵院

- 继续依古战场与镇魂地而立。  
- 该战场 / 镇魂地的来历本轮另案，不写成真龙混战伤疤。

## 5. 当前停点

真龙史这条线的原因、参战方类别、威压技能和婚约可见性已经够用。  
下一轮只谈十六势力对 **普通尸修 / 天罡尸魁术 / 灵械工业** 的态度，不重开大战对手。
