# 2026-08-12 尸魁体系、龙曦与灵械总纲回落纪要

## 总监确认

### 天罡尸魁术与僵尸娘

- 僵尸娘是 {{user}} 修炼天罡尸魁术后独有的炼制与驾驭能力。  
- 普通炼尸术存在，但不会产生美少女僵尸娘。  
- 正常对象必须是女性、原身貌美、尸身未腐烂且无大面积残缺，通常经防腐手段保存。  
- 探墓发现的是合格尸身，不是现成僵尸娘。  
- 活人可以炼制，但会招致天道天雷惩戒，修为不足可能被直接劈死。  
- 功法保留原本容貌与人格痕迹，并修复、美化、年轻化尸魁。  
- 茅山造型只是穿搭风格，额头符咒不承担真正控制效果。

### 灵识与成长

- 初阶尸魁没有灵识；后续产生的是新生意识，不默认等于原魂复活。  
- 若原魂或人格痕迹保存良好，新生灵识可以继承更多记忆与性格，但仍算新的生命。  
- 成长拆成「尸魁体 / 修为」与「灵识」两条线。  
- 阳精可作为食物与灵力炼化；交合不是唯一成长方式。  
- 其他资源都可参与供养，但精血、魂魄须由 {{user}} 辅助炼化，否则会污染灵识或导致躯体异化。

### 天道、古墓与以沫

- 开局先在界限空间见天道化身；她像因无聊而给穿越者整花活的异世界女神。  
- {{user}} 选择核心构筑，自定义灵根、血脉、天赋等词条，再选择降临地点。  
- 古墓是半固定降临点，是否进入由开局选择决定。  
- 古墓黄金棺同时承担尸身保存、防腐温养与残魂 / 人格痕迹封印。  
- 棺中以沫尚未炼制；尸魁术路线可将她炼成首位尸魁。  
- 纯灵械路线中，以沫可成为前期致命小 Boss，基本只能以强行体内注入阳精建立驯化与依赖；这不是正规尸魁契约。

### 上古真龙公主·龙曦

- （已由 plan-v1.5 迁移）龙曦封印前完好无缺；因折叠龙庭存续过久且无人能够唤醒，时间、生理活动与力量循环才长期停在零界点。外部观感近似死亡，但她并未死亡或濒死。  
- 保留龙角，龙尾可自由收放，无体表龙鳞，不需要尸龙形态。  
- 自带强烈真龙威压，需要主动长期抑制。  
- 她携带上古龙族之父留下、与天道及 {{user}} 有关的长久真龙婚约。  
- 身负真龙血脉前来者会被她视作命定夫君。  
- 当世真龙近乎灭绝、残余龙族血脉稀薄；「真龙血脉后裔」是可选血脉词条之一。  
- 龙曦对真龙血脉阳精的适配度最高。

### 灵械与军工

- 灵械通鉴采用完整百科型，不是残卷或等级解锁树。  
- 知识覆盖手枪、半自动 / 自动枪械、浮游炮 / 刃 / 盾、飞机、坦克、高达等。  
- 第一把灵械由 {{user}} 的能力、修为、材料和现场条件实际构成，不设固定模板。  
- 弹药为双模态：灵石加工成一次性击发灵弹；实体弹通常承担特殊用途并具有可回收属性。  
- 个人精品、兵工坊量产与完整军工体系全部允许，但不强迫建厂、建国或建立帝国。
