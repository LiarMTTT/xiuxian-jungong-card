# 2026-08-13 当世真龙绝迹史、蛟种压制与龙裔处境

> 状态：已确认并回落  
> 权威摘要：`plan.md` plan-v0.8  
> 适用范围：真龙绝迹原因、龙种阶序、血脉压制、龙裔社会处境、婚约可见性  
> 不包含：上古大战的具体对手名单、龙曦封印地点、婚约条款正文、完整下级龙种名录

## 1. 本轮确认

1. 当世真龙绝迹的直接历史是 **上古大战**；龙曦的保护封印发生在 **终战之前**，不是战后冷藏或战利品。  
2. **蛟本来就是龙的一种**；真龙血脉对下级龙种有精神上的巨大压制。  
3. 稀薄龙裔的社会待遇 **A / B / C 同时存在**，情况各不相同，不设全球统一政策。  
4. 真龙婚约在当世 **几乎无记载**，完整内容只有龙曦自己知道。

## 2. 上古大战与终战前封印

- 当世没有完整真龙种群，是因为上古大战，不是因为玩家还没去复仇或复国。  
- 父亲在终战前把龙曦连同完整龙体保护封印起来，自己进入终战；完整真龙没有从那场终战里走回来。  
- 封印是大战流程的一部分，用来保住火种，不是事后纪念馆。  
- 不上古大战写成必须通关的主线，也不把当前十六席里的任何一家写成自古存在、凌驾格局的灭龙元凶。  
- 现有势力最多继承废墟、镇魂义务、材料利益或官方史解释权。大战对手仍待确认。

## 3. 蛟是龙，但不是真龙

- 蛟属于下级龙种，不是「名字沾龙的独立海族」，也不是被开除出族的政治修辞。  
- 真龙血脉对蛟及其他下级龙种有巨大精神压制。  
- 沧溟海庭仍以蛟族领衔、多海族共治。蛟是龙，不等于海庭或四海盟约持有真龙继承权。  
- 龙曦必须长期主动抑制的真龙威压，与血脉对下级龙种的精神压制同属高位效应；两条都不改成额头符咒或系统提示。  
- 完整下级龙种名录本轮不展开。

## 4. 稀薄龙裔：三种处境并存

没有统一户口政策。随浓度、证物、地点和碰上谁，同一类人可以完全不同命，也可以从一种处境滑向另一种：

- **A 噪声**：无法验证或浓度不够的自称。民间不当真，坊市当酒话。  
- **B 争夺**：浓度或证物足以成为血脉、婚配、材料或政治旗帜。相关势力会抢、买、养、绑。  
- **C 禁忌**：接近真龙级、能触发下级龙种精神压制，或触及上古大战封存风险。会被视为需要镇压、封印或抹去的苗头。

不把「真龙血脉后裔」写成隐藏皇族自动复国资格。

## 5. 婚约可见性

- 真龙婚约几乎没有当世史料。  
- 合欢宗婚契库、天机楼档案、仙朝国史、道盟典籍默认都不掌握这份契。  
- 深层秘密可以涉及「终战前有完整封印 / 可能有公主」，这不等于泄露婚约正文。  
- 他人除非从龙曦处得知，否则不应在开局情报包里读到婚约。
