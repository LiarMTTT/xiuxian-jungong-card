# 2026-08-13 固定世界规模、势力与地图情报归档

> 状态：已确认并回落  
> 权威摘要：`plan.md` plan-v0.7  
> 适用范围：基础世界的空间、情报、势力与扩展骨架

## 1. 本轮确认

此前四项提案已经逐项获准：

1. 世界规模采用“大而可旅行”；  
2. 地图认知采用公开地理到世界真相的五层模型；  
3. 官方主要势力采用 16 席、4＋8＋4；  
4. 扩展采用三块海外锚点＋九域内部叠层，并允许追加、替换、叠层混用。

这四项自本次归档起成为基础世界 v1 的冻结基线。以后可以修改，但须按“先说明旧基线、冲突与影响，再确认修改并保留变更记录”的规则处理。

## 2. 世界尺度：大而可旅行

- 凡人跨域通常需要数月至数年。  
- 中阶修士跨域通常需要数周至数月。  
- 高阶修士跨域通常需要数日至数周。  
- 大型传送阵稀缺、昂贵、难维护，并受主要势力控制。  
- 道路、河运、海运与飞行仍是日常长途交通的主体。  
- 核心大陆总体西北高、东南低。天衡中域是河湖平原与交通中心，但山口、河谷和运河形成可争夺、可控制的通道，不是毫无遮挡的一张大平板。

地图像素尺寸、瓦片数量和缩放层级只是预览技术参数，不能反推世界物理面积。

## 3. 九域

### 3.1 核心大陆五域

- **天衡中域**：河湖平原、盆地与运河构成大陆交通中枢；通达但并非无险可守。  
- **青岚东域**：海岸山地、河谷与近海岛屿并存，剑宗、工造与港口密集。  
- **昆墟西域**：高原、荒漠、古战场与镇魂地并存，山口和绿洲决定旅行路线。  
- **苍梧南域**：湿润群山、大江、森林与云梦泽，多族群、多灵兽。  
- **朔原北域**：寒原、黑山、阴脉与矿区，资源丰厚但生存成本高。

### 3.2 四海

- **沧溟东海**：大陆架、海沟与水下城群；蛟族领衔、多海族共治。  
- **雾渊西海**：异常洋流、长年海雾、沉没遗迹与漂移界域；可靠航路知识比固定地标更重要。  
- **朱明南海**：火山群岛、港口、舰队与季风航线；造船、海运与大宗交换发达。  
- **玄冰北海**：浮冰、冰岛、极夜海域与深海沟；危险和资源并存。

北方继续作为冰洋、极夜与未知深海，不再放置第四块海外大陆。

## 4. 地图情报五层

| 层级 | 名称 | 交付原则 |
|---|---|---|
| 1 | 公开地理（public） | 可进入玩家基础包的常识地理 |
| 2 | 行业 / 旅行地图（travel） | 随商路、航海、旅行知识获得 |
| 3 | 势力情报（faction） | 按关系、渗透、交易与档案权限获得 |
| 4 | 深层秘密（deep-secret） | 满足发现条件后单独交付，不随基础运行时下发 |
| 5 | 世界真相（world-truth） | 作者母本，不属于普通情报 |

核心工程原则：秘密不能只是存在前端然后用 CSS 隐藏。深层秘密和世界真相必须分包、分索引、分条件交付，避免被搜索、缓存或上下文提前泄露。玩家公开检索只索引当前已获得的情报层。

## 5. 十六个官方主要势力

十六席采用 **4 个世界支柱＋8 个区域霸主＋4 个跨域专门势力**。这是基础世界的官方开局基线，不是运行时全部势力的数量上限。

### 5.1 四个世界支柱

#### 紫宸仙朝

- 中域仙朝，是唯一中央集权型世界支柱。  
- 直接控制中域核心领土，王族、官僚和军队修仙化，但绝大多数人口仍是凡人。  
- 国家修仙化不自动等于正义，也不代表其他凡人国家都采用同一模式。

#### 太玄道盟

- 无统一领土的玄门宗派联盟。  
- 盟山位于中域与东域交界，成员遍及大陆且保留自治。  
- 传统话语和秩序标准不等于客观天理。

#### 万灵妖庭

- 位于南域与西域之间的原始群山，直辖核心妖土。  
- 其他妖国、灵兽族群可以臣服、结盟或独立。  
- 妖庭不代表所有妖族，也不天然与人族为敌。

#### 四海盟约

- 无主权领土的海上条约组织，以中立岛仓、航线与契约协调防务和贸易。  
- 不能号令四海霸主，也不是龙族继承权持有者。  
- 它是海上合作机制，不是统一海洋帝国。

### 5.2 八个区域霸主

- **太阿剑宗**：青岚东域；太玄道盟重要成员，但高度自主。  
- **须弥梵院**：昆墟西域；依古战场与镇魂地而立的独立佛门圣地，不正式隶属道盟。  
- **苍梧巫盟**：苍梧南域；部族、巫门与血脉传统组成的松散联盟。  
- **朔冥圣宗**：朔原北域；有固定领地、产业和秩序的复合魔宗，涵盖魔功、血道、魂道、咒法、尸傀与魔器，尸道只是分支之一。  
- **沧溟海庭**：沧溟东海；蛟族领衔、多海族共治，对四海盟约保持警惕。  
- **逐星仙城舰盟**：雾渊西海；由移动主仙城与舰队组成，专长探索、打捞与航海。  
- **朱明群岛盟**：朱明南海；岛国、海宗与舰队联盟，掌造船、海军和大宗运输。  
- **玄冰镇海宫**：玄冰北海；专长寒法、封印、深海探索与大型海兽战斗，行动首先服从领地、资源与生存利益。

### 5.3 四个跨域专门势力

- **合欢宗**：总部在南域 / 中域交界的大湖与水路节点；婚契、艺术、双修和秘密网络遍及九域；不做简单正邪二元化。  
- **万宝商盟**：总部位于不受仙朝直辖的公认商贸城；掌贸易、物流、拍卖与金融，以信用、风险和自身利益行事。  
- **天机楼**：总部位于西域高地观星台；经营分楼、地图、卜算与档案，但不全知。  
- **百工天府**：位于东域山河港口交汇处；掌炼器、阵法、标准、大型工程与部分造船，同太阿剑宗合作但保持独立。

## 6. 开局关键关系

只固定下列开局连接，不穷举全关系网，也不预写后续外交结果：

- 紫宸仙朝—太玄道盟：合作兼制度竞争；王朝秩序与宗门自治长期拉扯，世界性灾害前可以协作。  
- 紫宸仙朝—万灵妖庭：边境摩擦与资源贸易并存，不设永久人妖大战。  
- 太阿剑宗—太玄道盟：重要成员与自治强宗。  
- 须弥梵院—太玄道盟：独立合作并有教义辩论。  
- 苍梧巫盟—万灵妖庭：血脉与贸易接近，同时竞争领地；巫盟拒绝被吸收或代表。  
- 朔冥圣宗—太玄道盟：长期竞争，也会为公共灾害进行必要合作，不固定为永恒正魔战争。  
- 沧溟海庭—四海盟约：参与但警惕，反对盟约稀释海族主权。  
- 逐星仙城舰盟—四海盟约：依赖并支持开放航路与跨海补给。  
- 朱明群岛盟—四海盟约：推动规则，也维护本方成员特权。  
- 玄冰镇海宫—四海盟约：仅在深海灾害、封印和共同防卫上有限参与。  
- 合欢宗—天机楼：情报交换与互相戒备并存。  
- 万宝商盟—百工天府：供应合作与定价竞争并存。

## 7. 仙凡社会与道途立场

- 紫宸仙朝是少见的修仙国家化成功案例，不是所有凡人国家的模板。  
- 普通国家主要处理人口、土地、税法、农业、道路、城市、工匠、市场与常备军，可以是世俗附庸、受宗门保护，也可以保持较低干涉。  
- 修士通常不治理凡世，主要因为治理回报低且无助修行，不是因为凡人国家足以正面对抗顶级宗门。  
- 军队、城防阵法、供奉、资源和组织能力能处理普通及部分中低阶修士；高阶修士仍有压倒性的个体力量。  
- 灵械军工若由玩家真正建立并扩散，可以改变仙凡生态；它不是开局已存在的成熟科技帝国。  
- 功法路线不等于客观道德。无差别血祭、失控尸灾、灵脉污染和魂灾属于多阵营都会追剿的公共灾害。普通尸道、天罡尸魁术及其具体行为必须分开判断。

## 8. 扩展锚点与玩家建宗

### 8.1 海外与九域内部

- 核心大陆东侧：不完整海岸线与少量旧航路；内部地理、势力、资源和历史全部留白。  
- 核心大陆西侧：雾流背后的模糊陆影；内部全部留白。  
- 核心大陆南侧：季风航线尽头偶见的海岸记录；内部全部留白。  
- 三块海外陆地都不占十六席。  
- 九域内部可用秘境、洞天、地下层、漂移界域和新发现区域继续叠层。

### 8.2 接入方式

扩展支持 **追加、替换、叠层**，并可混用。开局后新增内容必须通过迁徙、跨界、远航发现、秘境开启或真实建设进入世界，不得无因从后台生成。

### 8.3 势力数量与成长

普通国家、小宗门、家族、商会和地方组织不受十六席限制。玩家可以建立宗门，但必须通过领地、人口、资源、传承、组织、外交和实际影响逐步成长；不能点击一次“建立宗门”便自动成为第十七个世界支柱。

## 9. 地图视觉原型验收记录（非正典，暂停）

当前 Pages 预览已能在手机和电脑打开，平板无法访问属于设备 / 网络链路问题，不再视作部署失败。但视觉与交互验收未通过，后续若重启地图制作，必须继承这些反馈：

- 城市、宗门、建筑和地标不应写死进底图，应作为独立可切换叠加层。  
- 默认不展示一大堆地点；应以少量重要目标和按需展开为主。  
- 城市 / 地标优先采用鼠标悬停辉光、点击锁定高亮等交互。  
- 初始视野不能把整版地图完全拉满，应通过视窗尺度、留白与层级建立“大陆远比屏幕大”的宏大感。  
- LOD 必须在放大后出现真实的清晰度或细节提升；仅更换同等观感的瓦片不算有效。  
- 缩放与拖动必须顺滑。  
- 城池、建筑与地标需要独立的修仙文明美术语言，不能只靠文字点位交差。

以上是未来地图重做的验收输入，不会反过来污染世界正典；当前地图可以整版推倒。
